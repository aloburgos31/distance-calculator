# distance-calculator

## Description
My program calculates the distance between different point.

## How to Run
1. Open the program.
2. Run the program.
3. Enter the required values.

## Input Needed
```text
x_coordinate1= X Coordinate 1,
y_coordinate1= Y Coordinate 1,
x_coordinate2= X Coordinate 2,
y_coordinate2= Y Coordinate 2
```

## Sample Output
"The distance between the points is 5 units."
