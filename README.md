# distance-calculator

## Description
My program calculates the distance between different point.

## How to Run
1. Open the program.
2. Run the program.
3. Enter the required values.

## Input Needed
- The values that are needed to enter are x1, x2. y1, and y2.

## Sample Output
"The distance between the points is 5 units."
